Method

Two vision-language models read the same photograph and each write what they found in it. Neither returns a number.

What runs

Both are LLaVA-style models with two vision towers. A CLIP tower and a DINOv2 tower read the image; a Vicuna-13B decoder writes the answer as prose. Serving a request holds 26.8 GB of weights resident on the GPU.

Answers run 45 to 62 words. The generation cap is 512 tokens; when a model hits it and stops mid-sentence the response is flagged truncated, and the page says so rather than presenting half a note as finished.

What we changed

LoRA adapters on the released checkpoint: 62,586,880 trainable parameters, 0.799% of the model. Both vision towers and the whole fusion stack were frozen, and are bit-identical before and after training. This is not a model trained from scratch.

What the system does not produce

  • No confidence score. One was built from a logit pass and deliberately deleted for being fragile and unfaithful to the model. There is no meter, gauge or percentage of certainty anywhere on this site.
  • No heatmap. Nothing in the response is spatial — no attention overlay, no bounding box, no per-region score. The model's evidence is its prose.
  • No third verdict. The prediction is only ever real or fake. There is no uncertain state to fall back on.
